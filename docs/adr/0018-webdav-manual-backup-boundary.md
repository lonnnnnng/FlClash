# WebDAV 手动备份边界与冲突语义

状态：accepted

KClash 的 WebDAV 只提供用户主动触发的连接测试、上传和下载恢复，不实现周期同步或后台云端合并。WebDAV 账号和密码使用 Android Keystore 生成的 AES-GCM 密钥加密后写入独立偏好存储，不进入 Room、备份 ZIP、日志或普通对象的字符串表示。

上传使用同名文件的 HTTP PUT，并在页面中明确提示“覆盖远程文件”，只有用户确认后才执行。下载先完整取得远程 ZIP，再交给现有 `BackupRepository` 校验清单、文件路径和数据版本；恢复继续使用“兼容”或“覆盖”策略，由用户主动选择。网络失败、归档校验失败和恢复失败都不会自动清理或改写本地数据。

这个边界让远程传输复用本地备份的数据完整性和回滚逻辑，同时避免把密码带入云端同步、冲突自动解决和不可审计的后台任务。后续若引入真正的远程服务回归或云端同步，必须单独定义服务认证、版本冲突和离线重试语义，不能把手动 PUT 行为扩展成隐式同步。
