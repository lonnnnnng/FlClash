# KUI-023：菜单主体投影与回源层级对齐

2026-11-09，基线 `af1e3578`。本组修复Kotlin菜单与固定Flutter/Prism源码的阴影、裁剪、回源缩放和顶层矩形差异。KUI-022隐藏源按钮涟漪优化及网速卡紧凑布局保持；本组不把视觉修正称为性能优化。

## 固定来源与差异

参考Flutter `be84736605527034689c95bf27828ff27d912c5e` 所固定的Prism `63450c0`，本机只读参考位于 `../acceptance-artifacts/visual-motion-20261107/reference/prism_ui/lib/`。没有合并Flutter提交，也不修改参考包 `com.follow.clash`。

- `liquid_glass.dart::menuShadows` 使用blurRadius29、y偏移8、透明度0.118（深色乘1.5）。Flutter `Shadow.convertRadiusToSigma` 为`radius*0.57735+0.5`，其sigma为17.24315逻辑像素。旧Kotlin将29/2当sigma；Android再按物理像素换算时又引入密度偏差。新逻辑从Flutter sigma换回Android物理半径，根卡、动态子卡和外层共用。
- `popup.dart::_paintShadows` 给platter（菜单主体）投影，并以三倍sigma加偏移限制外界、用evenOdd扣除联合轮廓内部。旧Kotlin对主体与液滴的联合轮廓直接dropShadow，分离液滴也投影，透明玻璃内部可能被染黑。新外层仅绘制主体阴影，按相同范围扣内部。
- `_paintReturn` 中普通卡片自身的填充/阴影随正文先淡出，外层阴影强度为`remaining*(1-reveal)`；玻璃内容保持裸绘制，由外层贯穿承担。旧Kotlin关闭时立即隐藏内部阴影且外层始终全强度。新帧分别保存回源标记与剩余阴影强度，保留两条时间线。
- `_paintReturn` 按当前顶层卡片矩形作为closingSurface，以宽高缩放比最小值等比收回，回源正文不按platter裁剪。旧Kotlin使用整个栈的宽度缩放且始终裁剪，关闭子菜单时可能把后层/阴影带入或切掉。新逻辑快照实际顶卡矩形（独立于可能受入场裁剪的触点范围），回源只绘制顶层，保持其余层组合身份；正文阴影的图层范围留出模糊边界。

源码参考证明本次参数与绘制意图有据可查；尚未完成相同Flutter运行时截图的逐像素对照，不能据此宣称完整Flutter视觉一致。其他液滴曲线、源图像模糊及玻璃材质差异仍按原清单继续。

## 验证方式与失败保留

新增3项JVM测试覆盖普通/玻璃阴影接续、不同密度下sigma、顶层矩形及等比缩放。新增真机像素测试将阴影单独画到背景上，检查主体内部透明、分离液滴内部与周边无独立投影、主体下方有投影、强度归零无残影；正式背景填充不能遮掩错误。显式旧联合轮廓分支红测在“主体内部不能被阴影染黑”失败，正式platter路径通过；旧分支复用本次半径，仅用于证明轮廓/扣除断言有效，不冒充旧APK全量回放。

新增多层菜单选择回源：64ms时动作未执行且源按钮隐藏，过程图只有顶部短卡；回源后仅执行一次，按钮恢复并可重开。既有真实触点开合、中断、拖选、后台撤销、长菜单滚动、键盘层级、配置来源、正文撤销重做和Provider过滤继续回归。

首轮编译失败 `DSL_SCOPE_VIOLATION` 来自clipPath内隐式ContentDrawScope接收者，改为显式接收者；日志保留。第二个GPU阴影试验也出现绘制作用域toPx错误，修正后进入固定帧门禁。

GPU主体阴影候选保持同一轮廓、sigma、扣除和强度，以GraphicsLayer/BlurEffect替换软件栅格化。浅色打开140ms固定帧最大通道差4、平均差0.420345，未通过既定max3/mean0.2；4张失败图保留，没有进入正式性能测试，代码/测试移至本机附件，不在最终主线保留。没有放宽外观门槛。
