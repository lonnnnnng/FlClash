# NTP 输入弹框连续动效

2026-11-20，KUI-VIS-061；POCO F2 Pro（31936bb6/API36），竖屏、默认字号，玻璃默认关闭。承接060，只修改NTP标量弹框动效与对应生命周期，原版Flutter包不操作。

## 来源与实现

固定Flutter副本`../acceptance-artifacts/docked-search-20261110/flutter-full`的Prism `dialog.dart`、`motion.dart`与本机Flutter SDK物理实现是来源。路由时长404ms，物理参数由275ms/零bounce产生临界阻尼；令ω=2π/0.275，x(s)=1−(1+ωs)e^(−ωs)，f(p)=x(0.404p)+(1−x(0.404))p。

- 入场透明度f(p)、缩放1.2−0.2f(p)；完整入场后退出透明度1−f(1−p)、缩放固定1。入场中返回保留入场曲线f(p)，冻结关闭时的缩放，剩余时长随当时进度缩短。不能把完整退出公式套到提前反转。
- 内容透明度与缩放只在图层阶段读取；同弹框遮罩在绘制阶段使用相同进度，最大深48%/浅20%。禁用系统额外Window动画和dim，避免双重动画及每帧重组整个表单。
- 开始关闭立即阻止输入/提交/返回再入，按钮保留退场前颜色，动画结束才移除窗口；业务保存仍在确认时调用一次，不随动画或恢复重放。
- 父层保留标量打开时的JSON快照，清空保存后字段虽已移除，弹框仍完成淡出。配置/分区/字段身份隔离，旧配置关闭协程不能污染新配置同名输入。
- 系统动画比例由Compose MotionDurationScale传入；0时直接结束当前动画。关闭中重建只完成移除，不重播入场或提交；外层宿主整体卸载不承诺继续局部退场。

## 候选问题与证据边界

首轮`build1`新增动画单测失败：分段推进404ms后Float残差导致`moving`仍为true，可能多保留一帧透明窗口。端点容差归零后同测试通过；保留原失败，不称自然用户缺陷复现。

静态审查指出配置身份复用风险，当前入口能否自然触发未证实。标量输入与动画按身份隔离，编辑目标也按profile/section保存；新增受控身份切换测试覆盖旧窗口关闭中切新配置、打开新字段仍可编辑。

初批`final1`为8/11：两项在新窗口首帧前操作，另关闭恢复测试冻结时钟时使用StateRestorationTester，未明确证明旧子树销毁。补首帧等待；恢复改为显式SaveableStateRegistry保存/卸载/挂载并断言dispose次数，`final2`11/11，产品不变。该解释是代码和后续证据支持的定位，不追认原恢复工具内部实际状态。

`final2`视觉核查发现浅色首次弹框重复压暗：稳定背景像素红通道93，同批普通字段弹框为191，目标本底约239。候选只设置dimAmount=0，首次挂窗可能重新应用系统主题dim。现显式清FLAG_DIM_BEHIND并在attach后再清；新增以父页同位置像素为基线的深浅遮罩断言。结果以最终批次为准，不能因前一批功能11/11而认定视觉已通过。
