# KUI-VIS-067 表单 Sheet 与实时材质

本组对照固定 Flutter 手机 `showNamedUrlsForm` / `SnapSheetRoute`，将链接导入改为底部 Sheet，统一远程订阅表单的同行输入。玻璃保持默认关闭；显式开启后，Dock 和首页启动按钮重放已有 GPU 背景层，加入触点亮光。

## 实现与保留行为

- 手机短表单沿用 9/16 停靠、上限 0.9、8dp 浮起、68dp 标题区、44dp 按钮、24dp 输入组和56dp同行字段。键盘先消化留白，再抬升面板；长批量正文独立滚动，顶部确认一直可达。
- 名称、链接、age 私钥与更新间隔使用共用输入行；必填/可选、分隔线、深浅分组底色和胶囊动作对齐。提交认领、防重、失败重试、后台清密钥、草稿恢复继续保留。批量识别数量、下载/解密/校验反馈是Kotlin已确认交互，因此高度不强行等同仅收集输入的Flutter表单。
- 实时背景使用独立 `GraphicsLayer`，背景不包含消费它的文字与触光；没有循环PixelCopy或截图协程。API33使用边缘折射与模糊，31/32仅模糊，旧API染色降级；本次仅POCO API36验证，不追加低API边界。
- 根导航两种材质保持同一个组合位置，实色时预留Dock空间，玻璃时列表内部增加底部留白，内容可经过Dock。现有Popup菜单仍冻结背景，不将菜单采样改成实时。
- 玻璃关闭不创建实时背景层或触光动画。开启设置独立保存，不重启核心、不改变主题/语言选择。

## 本轮发现并修复

1. Sheet终态仍被submitted锁挡住关闭：终态明确允许退出，新增完成后返回测试。
2. 旧两分支导航虽共用SaveableStateHolder，切换玻璃时新registry先于旧页dispose保存，导致当前草稿丢失；POCO visual4 6/7复现，统一组合后visual5 7/7。
3. 根内容外层留白让Dock下方无可采背景；改由各列表承担末项留白。顶卡背景不再参与测量后高度可能改变，保留240dp最小高度。
4. 默认关闭仍释放触光弹簧；现在仅开启玻璃创建与驱动触光。
5. Lint不能从nullable对象来源推断API33调用安全，调用点增加显式SDK分支。
