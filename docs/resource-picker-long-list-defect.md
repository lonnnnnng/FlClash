# KUI-030：资源长目录打开时未显示当前选择

2026-11-10，作者 long。产品基线 `37f3e8b09ee6fa1704c31a0b95d3af8dadbed1be`，范围是配置中的代理资源、规则资源绑定选择页；不是系统 SAF 文件选择器。

## 来源与红测

Flutter 固定参考 `be84736605527034689c95bf27828ff27d912c5e` 的 `lib/features/form/selection_sheet.dart`：`_revealRequested` 只在首次布局后定位已有选择，`_revealSelected` / `_alignSelected` 在选择超出可见区域时居中，已可见时不滚动。Kotlin 两个绑定页原先使用无显式状态的 `LazyColumn`，每次打开均从顶部开始；长目录中的原绑定存在，但用户看不到它。属于 Kotlin 行为缺口，不是上游源码缺陷，也未合并 Flutter 提交。

Redmi API36 独立非 debuggable `.motion` 包、64 项内存目录、原选择索引45：旧源码两个测试均在“当前项应可见”失败。首批被锁屏/USB系统窗口遮挡的 `No compose hierarchies` 独立记为环境失败，解锁后的两项可见性失败才是产品红测。

## 修复

`ResourcePickerListState.kt` 提供两页共用的首次定位状态。等待实际目录布局，按当前绑定 ID 查找；选择不可完整显示时滚入视口，再根据实测行高和视口居中。每次打开只定位一次，搜索过滤和用户滚动不会反复被拉回。关闭重开依据最新绑定重新定位，不改变资源、配置别名或保存路径。

## 验收合同与失败保留

`ResourcePickerLongListInstrumentedTest` 的两种资源各覆盖：原选择显现、真实 IME 下无结果清除、清除后滚到末项、末项完全位于键盘上方、选中前零写入/选中后一次回调及别名保持、重开显现末项、取消不再提交。64 项为内存 UI 目录，不生成真实验收 YAML，不接正式 Room 或网络。

开发绿测的两个失败批次来自清空断言：先把占位文字当作输入，随后比较包含样式的 `AnnotatedString`。原始语义回读均为空文本；最终按既有测试模式只比较 `EditableText.text`。失败日志不删除，不把这两个断言问题记为产品修复。

最终相同motion双包：深色2/2、浅色2/2、相邻回归2/2，4个不重复方法共6次执行通过；23PNG哈希及4拼图目视已核验。865项JVM（App583执行、其余282复用）、Debug/签名Release-R8与双Lint零错误通过。本地签名候选已安装回拉，配置正文/选择保持；3个自有测试包及12个手机诊断文件精确清理。具体批次、深浅截图、构建与设备状态见 `docs/acceptance/post-release-boundaries-redmi-20261110.json`。本组不证明完整 Flutter 页面像素等价、工具栏搜索展开动效、长目录所有字体/方向、冷进程或正式库64资源表现。上游后续同步需保留只在首次打开显现当前项的行为，若统一选择器取代此实现，应先通过同组回归再移除助手。
