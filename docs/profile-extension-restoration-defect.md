- 归属：Kotlin扩展页生命周期集成；不是Flutter或Mihomo上游源码缺陷。

## 触发、影响与参考

真实MainActivity中打开非当前FILE的扩展，进入全局规则子页或滚到长脚本列表末尾后重建Activity，旧实现会退回父页或回到顶部。旧实现挂起保存单测进一步确认：重建再次open使saving/profile被重置，已受理写入可能落库但原代际结果被丢弃。

Flutter只读参考`lib/views/profiles/extend/extend.dart`的同配置Provider观察、显式应用与退出自动应用，`standard.dart`规则表单确认后put，`script.dart`同项选中/取消及脚本库返回。它们提供交互参考，不表示存在相同Android生命周期缺陷，也未合入Flutter代码。

## 修复与回归要求

同一扩展会话重复open保持正在加载、保存及已加载状态；明确重试才reload，正常退出或暂不应用退出清除会话身份。配置切换仍递增代际并拒绝旧结果。表单错误与放弃确认使用saveable状态，正文冷进程持久化仍另行处理。

回归要求包含：正式主宿主目标选择草稿/放弃确认重建、全局子页逐层返回、长脚本列表恢复/绑定/解绑/脚本库往返；挂起保存不作废、加载重连不重复读取、显式重试和关闭后重新打开会读取。测试只修改原1.yaml非当前副本和自身脚本，保护正式配置/脚本/源文件/偏好/选择与STOPPED。

后续更改扩展路由、Controller生命周期或保存队列时必须复验上述场景，等价修复及回归通过后才撤销本地处理。本文件与修复同次提交，以Git历史定位；不推广冷进程、运行态、完整Flutter视觉或全部低API。
