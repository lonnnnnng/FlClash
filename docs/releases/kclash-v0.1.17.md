# KClash 0.1.17

本版继续对齐 Flutter 页面与面板，改进配置空态、NTP 空态及主导航过渡；完善全局 DNS 字段选择、附加规则工具栏、快捷预设 Sheet 和新增规则表单，修复附加规则页在 Activity 重建时的状态恢复崩溃。

POCO F2 Pro 已完成本组规则保存、取消重开、Activity 重建与数据库回读回归，并补充真实页面连续路线录像。完整 Flutter 逐帧对照和菜单慢帧归因仍在推进，玻璃默认关闭。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.17-android-arm64-v8a.apk`，versionCode 为 1017，沿用既有正式签名，可覆盖安装之前的 KClash 正式版。
