# KClash 0.1.11

- 工具页将最近请求、活动连接、DNS 查询和运行日志整合为“网络活动”四个可搜索页签，收紧重复入口。
- 补齐应用中文和英文文案，语言支持中文、英文和跟随系统；主题支持浅色、深色和跟随系统。
- 改进 NTP、域名嗅探、资源选择与列表编辑面板，补充搜索、快速 YAML 编辑、输入校验和草稿保持。
- 链接导入改为底部 Sheet；重命名与 age 密钥输入采用统一浮框，完善键盘交接、进退场、忙态和失败重试。
- 优化添加配置、菜单和列表的部分分配与窗口交接，活动连接仅在可见页签轮询；修复菜单撤销后旧选择重放等问题。
- 完善可选玻璃的实时背景、折射、雾化、色散、Dock 镜片和触点光效。玻璃默认关闭。

最新一组已在 POCO F2 Pro 完成 37 项集中回归，921 项 JVM 测试结果无失败（含 Gradle 复用）。菜单首开仍有慢帧，完整 Flutter 视觉、连续转场与玻璃捕获分层尚未全部对齐，继续保留在 roadmap。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.11-android-arm64-v8a.apk`，versionCode 为 1011，沿用既有正式签名，可覆盖安装之前的 KClash 正式版。
