# KClash 0.1.21

本版本移除了全局图标集管理，并将本地代理、规则资源和过滤预设入口集中到“工具 → 高级配置”。策略组自己的图片选择与最近图片记录继续保留。

修复了没有可用配置时首页“允许局域网连接”开关无法操作的问题。此时开关只保存偏好，不启动 Mihomo；添加配置后按正常核心流程生效。

本版本按当前开发阶段重建 Room 数据库，不保留旧迁移链。升级可能清除应用数据库中的配置、脚本和偏好数据；升级前请准备好重新导入配置。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.21-android-arm64-v8a.apk`，versionCode 为 1021，沿用既有正式签名，可覆盖安装之前的 KClash 正式版。
