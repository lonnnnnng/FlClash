# KClash 0.1.22

本版本在“常规 → 核心”中增加测速地址、统一延迟、TCP 并发、IPv6 和 GeoData 加载器覆盖项。未显式选择的字段继续继承配置正文；默认测速地址用于应用级健康检查和手动测速，代理组自带测速地址优先。

运行中修改支持热更新的核心参数时，应用只更新对应核心配置；验证或更新失败会恢复原配置。影响 Android VPN 服务的有效参数变化会提示用户重启生效，保存设置不会静默打断当前会话。关闭外部控制器后会清除控制器密钥；未配置 User-Agent 时使用当前 KClash 版本默认值。

测速逻辑还修正了 Provider 节点的超时选择：只有与该节点及测速 URL 匹配的 Provider 显式超时才生效，并优先使用该期限，即使它短于应用通用超时。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.22-android-arm64-v8a.apk`，versionCode 为 1022，沿用既有正式签名，可覆盖安装之前的 KClash 正式版。
