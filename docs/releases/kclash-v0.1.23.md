# KClash 0.1.23

优化菜单展开和收回时的液滴轮廓计算：参考 Flutter 的自适应采样，只在轮廓交界和误差较大的位置补点，减少重复计算，保留原有动画时长、材质和交互。

POCO 真机局部轮廓计算中位耗时降低约16%；几何、取消、子菜单回源和阴影回归通过。该结果不代表整体掉帧率已经稳定改善，菜单首次建窗与部分渲染慢帧仍在优化。玻璃默认关闭。

本次还补齐常规设置的冷恢复、VPN显式重启和核心拒绝参数后的回滚验收记录。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.23-android-arm64-v8a.apk`，versionCode 为 1023，沿用既有正式签名，可覆盖安装之前的 KClash 正式版。
