# KClash 0.1.14

- 仪表盘运行、网速、配置和代理组卡片在加载、失败、长值和空态之间保持固定高度；数据等待时使用骨架占位。
- 网速主数值与单位按层级显示，配置统计区收紧到与 Flutter 手机上游卡片相近的高度。
- POCO F2 Pro / Android 16 完成卡片深浅主题与四态定向验收；全页视觉和菜单性能仍按 roadmap 继续推进。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.14-android-arm64-v8a.apk`，versionCode 为 1014，沿用既有正式签名，可覆盖安装之前的 KClash 正式版。
