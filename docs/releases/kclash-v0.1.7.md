# KClash 0.1.7

- 修复自定义配置导入较大规则目录时卡在替换确认的问题。已在 POCO F2 Pro 上验证一份含 92 个缓存规则资源的配置可以一次完成校验并应用。
- 修复删除 NTP 或 Sniffer 最后一个字段时，字段行在退场动画中提前消失的问题。
- 改进代理组编辑。选择回退或默认目标时可以看到当前选项，长列表会定位到选中行。添加设置项时，候选达到 10 项即可搜索，连续添加只更新当前草稿。
- 整理自定义配置概览中的规则、资源、DNS 和更多入口。规则资源搜索无结果时可以直接清除搜索，恢复选择。

POCO F2 Pro（Android 16）上的 8 项界面用例通过。另用在线订阅抽测了 Trojan、Hysteria2 和 VLESS，每种协议两个端点，6 次 HTTPS 请求均通过。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.7-android-arm64-v8a.apk`，版本号为 1007，可覆盖安装之前的 KClash 正式版。
