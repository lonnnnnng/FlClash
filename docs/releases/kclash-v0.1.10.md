# KClash 0.1.10

- 启用全新「折流 K」应用图标，采用青绿底、近白主干与薄荷色折面。
- 完整提供方形、圆形、自适应及系统主题单色图标，补齐旧版 Android 五档分辨率资源。
- Redmi Note 8 Pro（Android 16）独立验收包的系统圆形图标已验证；其他 OEM、低 API 真机和桌面主题图标开关未单独实测。

适用于 Android 7.0（API 24）及以上的 ARM64 设备。安装包为 `KClash-0.1.10-android-arm64-v8a.apk`，versionCode 为 1010，沿用既有正式签名，可覆盖安装之前的 KClash 正式版。
